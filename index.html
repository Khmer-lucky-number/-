ភ្នាក់ងារជ្រើសរើសបុគ្គលិកទូទៅ

សូមស្វាគមន៍មកកាន់ទំព័រប្រកាសការងារ និងដាក់ពាក្យធ្វើការ

🏠 ទំព័រដើម 📋 ច្បាប់និងរបៀបប្រើប្រាស

🏠 ការងារកំពុងមាន

Web Developer

⏰ ពេញម៉ោង 📍 ភ្នំពេញ 🏠 ពីចម្ងាយ 📅 កាលបរិច្ឆេទ: 01/08/2026
ប្រាក់ខែ: 300$ - 500$

ការពិពណ៌នា: កំពុងស្វែងរកអ្នកអភិវឌ្ឍន៍គេហទំព័រដែលមានបទពិសោធន៍ HTML, CSS, JavaScript និងមានជំនាញក្នុងការបង្កើតគេហទំព័រឆ្លើយតប (Responsive)។

📈 អត្ថប្រយោជន៍: 15$-20$ ក្នុងមួយថ្ងៃ + ប្រាក់រង្វាន់ប្រចាំខែ + ថ្ងៃឈប់សម្រាក

Graphic Designer

⏰ ក្រៅម៉ោង 📍 សៀមរាប 🏠 ពីចម្ងាយ 📅 កាលបរិច្ឆេទ: 01/08/2026
ប្រាក់ខែ: 350$ - 550$

ការពិពណ៌នា: រកអ្នករចនាក្រាហ្វិកដែលមានជំនាញ Photoshop, Illustrator, Canva និងមានគំនិតច្នៃប្រឌិតខ្ពស់។

📈 អត្ថប្រយោជន៍: 18$-22$ ក្នុងមួយថ្ងៃ + ថ្ងៃឈប់សម្រាក + ប្រាក់រង្វាន់

Marketing Specialist

⏰ ពេញម៉ោង 📍 ភ្នំពេញ 🏠 ការិយាល័យ 📅 កាលបរិច្ឆេទ: 15/08/2026
ប្រាក់ខែ: 400$ - 600$

ការពិពណ៌នា: រកអ្នកជំនាញផ្នែកទីផ្សារឌីជីថល មានបទពិសោធន៍ SEO, Social Media, Content Marketing ។

📈 អត្ថប្រយោជន៍: 20$-25$ ក្នុងមួយថ្ងៃ + ប្រាក់រង្វាន់ប្រចាំខែ + ការបណ្តុះបណ្តាល

Data Analyst

⏰ ពេញម៉ោង 📍 ភ្នំពេញ 🏠 ពីចម្ងាយ 📅 កាលបរិច្ឆេទ: 01/09/2026
ប្រាក់ខែ: 450$ - 650$

ការពិពណ៌នា: រកអ្នកវិភាគទិន្នន័យដែលមានជំនាញ Excel, SQL, Python និង Tableau។

📈 អត្ថប្រយោជន៍: 22$-28$ ក្នុងមួយថ្ងៃ + ប្រាក់រង្វាន់ + កញ្ចប់សុខភាព
